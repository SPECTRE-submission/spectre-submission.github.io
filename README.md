# SPECTRE project page

Static project page for *SPECTRE: Skeleton Priority Estimation Conditioned on TAMP Refinement Evidence*, a paper
under double-blind review at ICRA 2027. Authors and affiliations are withheld until the review process concludes.

The page is plain HTML and CSS served by GitHub Pages from the repository root (`.nojekyll` disables Jekyll).
There is no build step.

## Local preview

    python3 -m http.server 8000

then open http://localhost:8000.
